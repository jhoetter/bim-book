# Anhang A – Glossar

Über 100 Fachbegriffe aus Architektur, Bauphysik, TGA und BIM kurz erklärt.

| Begriff | Erklärung |
|---------|-----------|
| Armierungsputz | Zwischenschicht im WDVS: Klebemörtel mit eingebettetem Glasfasergewebe, schützt die Dämmung mechanisch |
| BAP | BIM-Abwicklungsplan. Projektdokument, das festlegt, wer welche BIM-Leistungen in welcher Phase mit welcher Software erbringt |
| BCF | BIM Collaboration Format. Offenes Format für Koordinationsanmerkungen am Modell (Kameraposition, Beschreibung, Zuständigkeit) |
| BIM | Building Information Modeling. Methode der vernetzten Planung, Ausführung und Bewirtschaftung von Gebäuden auf Basis digitaler Modelle |
| Dampfbremse | Schicht mit definiertem sd-Wert (0,5–1500 m), die Dampfdiffusion verlangsamt, aber nicht vollständig verhindert |
| Dampfsperre | Schicht mit sehr hohem sd-Wert (> 1500 m), die Dampfdiffusion praktisch verhindert |
| DVGW | Deutscher Verein des Gas- und Wasserfaches. Erstellt technische Regelwerke für Gas- und Wasserinstallationen |
| Embodied Carbon | CO₂-Emissionen, die bei Herstellung, Transport und Einbau von Baumaterialien entstehen (nicht im Betrieb) |
| EPD | Environmental Product Declaration (Umweltproduktdeklaration). Genormter Nachweis der Umweltauswirkungen eines Bauprodukts nach ISO 14025 |
| Eurocode | Europäische Normenreihe für die Tragwerksplanung (EN 1990–1999). Gilt in Deutschland als DIN EN mit nationalem Anhang |
| FBH | Fußbodenheizung. Flächenheizung, die Wärme über die Bodenoberfläche abgibt. Betriebstemperatur 30–45 °C VL |
| GEG | Gebäudeenergiegesetz. Deutsches Gesetz für energetische Anforderungen an Gebäude, seit 2020 in Kraft (EnEV-Nachfolge) |
| GFZ | Geschossflächenzahl. Verhältnis der Geschossfläche zur Grundstücksfläche; aus dem Bebauungsplan |
| Glaser-Verfahren | Vereinfachtes Rechenverfahren zur Bestimmung von Tauwassermengen in Bauteilen (DIN 4108-3) |
| GRZ | Grundflächenzahl. Verhältnis der bebauten Fläche zur Grundstücksfläche; aus dem Bebauungsplan |
| HOAI | Honorarordnung für Architekten und Ingenieure. Regelt Leistungsbilder und Mindest-/Höchsthonorare |
| hydraulischer Abgleich | Einstellung aller Heizkreise auf den berechneten Volumenstrom, um gleichmäßige Wärmeverteilung zu gewährleisten |
| IFC | Industry Foundation Classes. Offener ISO-Standard (ISO 16739) für den herstellerneutralen Austausch von BIM-Daten |
| Innenputz | Erste Schicht der Innenwandoberfläche. Kalk-Gips-Putz (λ ≈ 0,87 W/mK), 10–20 mm |
| KWL | Kontrollierte Wohnraumlüftung. Mechanisches Lüftungssystem mit Wärmerückgewinnung (η ≥ 75 %) |
| Lastfall | Definierte Belastungskombination für den Tragswerksnachweis (Eigengewicht + Nutzlast + Wind etc.) |
| LOD | Level of Development (früher: Level of Detail). Definiert den Informationsgehalt eines BIM-Modellelements (LOD 100–500) |
| Mineralwolle | Dämmstoff aus Glaswolle oder Steinwolle. Wärmeleitfähigkeit λ = 0,030–0,045 W/(mK), je nach WLG-Klasse |
| MBO | Musterbauordnung. Nicht-rechtverbindliches Mustergesetz, das von den Bundesländern als LBO (z.B. BayBO) übernommen wird |
| Primärenergiefaktor | fp. Gibt an, wieviel Primärenergie (inkl. Förderung, Transport) für 1 kWh Nutzenergie aufgewendet wird |
| R-Wert | Wärmedurchgangswiderstand einer Schicht in m²K/W = d/λ |
| REI | Feuerwiderstandsklasse: R = Tragfähigkeit, E = Raumabschluss, I = Wärmedämmung. REI 60 = 60 Minuten Widerstand |
| Schallschutz R'w | Bewertetes Schalldämmmaß in dB. Anforderung nach DIN 4109 für Wohnungstrennwände: R'w ≥ 53 dB |
| STEP | Standard for the Exchange of Product model data (ISO 10303). Serialisierungsformat für IFC-Dateien (.ifc) |
| TGA | Technische Gebäudeausrüstung. Oberbegriff für Heizung, Lüftung, Sanitär, Elektro und Gebäudeautomation |
| Transmissionswärmeverlust | Wärmeverlust durch Bauteile der Hülle (Wand, Dach, Fenster), berechnet über U-Wert und Fläche |
| U-Wert | Wärmedurchgangskoeffizient in W/(m²K). Je kleiner, desto besser die Wärmedämmung |
| VOB | Vergabe- und Vertragsordnung für Bauleistungen. Teil A: Vergabe, Teil B: Allgemeine Vertragsbedingungen |
| WDVS | Wärmedämmverbundsystem. Vorgehängte Dämmschicht (Mineralwolle oder EPS) mit Putzoberfläche, direkt auf der Wand verklebt |
| Wärmebrücke | Stelle in der Gebäudehülle mit erhöhtem Wärmestrom durch geometrische oder materialbezogene Unterbrechung der Dämmschicht |
| WLG | Wärmeleitfähigkeitsgruppe. Klassifiziert Dämmstoffe nach λ-Wert: WLG 030 = λ ≤ 0,030 W/(mK), WLG 035 = λ ≤ 0,035 W/(mK) |
